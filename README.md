# LibraryManagementSystem
A simple Java console-based Library Management System that allows users to add, search, borrow, and return books. It uses object-oriented programming concepts like classes, objects, encapsulation, and ArrayList to manage book records and availability through a menu-driven interface.

Overview:

The Library Management System is a console-based application developed using Java that helps manage books in a library. This system allows users to add new books, search for existing books, borrow books, return books, and view all available books. It provides a simple menu-driven interface for easy interaction and simulates real-world library operations.

Purpose:

The purpose of this project is to demonstrate how a library system works using Java programming. It helps in understanding object-oriented programming concepts and how to manage and organize data efficiently using collections like ArrayList.

Features:

This system allows users to add book details such as title, author, and ISBN. Users can search for books using the title or author name. The system also allows borrowing books if they are available and returning them after use. It maintains the availability status of each book and displays all available books when requested.

Project Structure:

The project is designed using object-oriented programming principles. The Book class stores book information and manages availability status. The Library class manages the collection of books and handles operations like adding, searching, borrowing, and returning books. The main class provides the menu-driven interface for user interaction.

Technologies Used:

This project is developed using Java and uses core Java concepts such as classes, objects, methods, ArrayList, loops, and conditional statements. The Scanner class is used to take input from the user through the console.

Summary:

This project is useful for beginners to understand Java programming and object-oriented design. It provides practical experience in building a real-world console application and managing data efficiently using Java.
